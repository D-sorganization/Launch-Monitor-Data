# Launch Monitor Data Project Charter

## End Goal

Provide share-safe schemas, validation code and an authenticated client for the
private launch-monitor data authority. Preserve source identity, units, rights
and cohort eligibility. The [README](../../README.md) describes the wider
platform; this initial feature list covers only deferred external dependencies,
so its counts do not measure whole-repository progress.

## Non-Goals

- Publish private shot data, source artifacts or participant information.
- Infer licenses, consent, measurements or campaign approval from software tests.
- Manufacture paired shots from aggregate observations.
- Assign unavailable collection or rights-holder responses to coding agents.

## Source Authority

The [catalog](../development/planning/catalog.json), owner plans and original
source snapshots retain acceptance and reactivation requirements. Software,
existing-source research and available-data analysis remain separate executable
work under their original issues. This projection supplies no new evidence or
outreach authorization. The private campaign retains collection/data authority;
update the owner record before refreshing this projection.
